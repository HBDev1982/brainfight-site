Política de Privacidade

Última atualização: 23 de outubro de 2026

O BrainFight é um jogo de quiz para jogar em grupo na mesma rede Wi-Fi. Esta política explica que dados a app usa e onde ficam.

Não recolhemos dados pessoais. O BrainFight não tem servidores próprios, contas de utilizador, publicidade nem rastreio.

Dados do jogo (ficam no aparelho anfitrião). Durante um jogo, o aparelho anfitrião (Apple TV ou Mac) recebe, pela rede local, o nome, o avatar e as respostas de cada jogador e, se o jogador o permitir, uma selfie de reação no fim do jogo. Estes dados são guardados apenas no aparelho anfitrião, para mostrar o jogo, o ranking e o histórico. O histórico de jogos é apagado automaticamente ao fim de 90 dias, e todos os dados são apagados ao desinstalar a app. Nunca são enviados para nós nem para terceiros.

Câmara. No iPhone, a câmara é usada para ler o código QR do jogo e, se o jogador quiser, para tirar selfies de reação. As fotos só são enviadas para o aparelho anfitrião na rede local.

Microfone. No Mac, o microfone é usado apenas se o anfitrião gravar falas no Estúdio de Voz. As gravações ficam no Mac.

Rede local. A app usa a rede local para ligar os telemóveis ao aparelho anfitrião e para o encontrar automaticamente (Bonjour).

Game Center. Se tiveres sessão iniciada no Game Center, a app envia à Apple as tuas pontuações e conquistas, para os rankings e conquistas do jogo. Isto é tratado pela Apple segundo a política de privacidade da Apple.

Crianças. A app não recolhe dados de ninguém, incluindo crianças.

Contacto. Para qualquer questão sobre privacidade: humbertobebianodev@outlook.com.

Privacy Policy

Last updated: October 23, 2026

BrainFight is a quiz game for groups playing on the same Wi-Fi network. This policy explains what data the app uses and where it stays.

We don't collect personal data. BrainFight has no servers of its own, no user accounts, no advertising and no tracking.

Game data (stays on the host device). During a game, the host device (Apple TV or Mac) receives over the local network each player's name, avatar and answers and, if the player allows it, a reaction selfie at the end of the game. This data is stored only on the host device, to show the game, leaderboard and history. Game history is deleted automatically after 90 days, and all data is removed when you uninstall the app. It is never sent to us or to third parties.

Camera. On iPhone, the camera is used to scan the game's QR code and, if the player chooses, to take reaction selfies. Photos are only sent to the host device on the local network.

Microphone. On Mac, the microphone is used only if the host records lines in the Voice Studio. Recordings stay on the Mac.

Local network. The app uses the local network to connect phones to the host device and to find it automatically (Bonjour).

Game Center. If you're signed in to Game Center, the app sends your scores and achievements to Apple for the game's leaderboards and achievements. This is handled by Apple under Apple's privacy policy.

Children. The app doesn't collect data from anyone, including children.

Contact. For any privacy question: humbertobebianodev@outlook.com.
